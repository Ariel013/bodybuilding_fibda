## API
Base `/api/v1`. Cookie HttpOnly same-origin session, login POST /auth/login {code}; POST /auth/logout; GET /auth/me → {user,event_id}. GET /health → {status,version,setup_required,demo,restore_id}. POST /auth/setup {name,code} crée premier chef uniquement sur serveur vierge (accès loopback). GET /state → état filtré selon rôle. GET /catalogue. POST /command {id:uuid,version:number,type:string,payload:object} → {state,result}. Chaque écriture administrative vérifie la version (409 → recharger/revoir) ; les bulletins simultanés admettent une ancienne version globale sous réserve des contrôles de tour, restauration, propriétaire et clôture, commande idempotente, droits serveur. GET /ws WebSocket signale {type:'state_changed',version} sans données privées ; recharger état. Service timer toutes secondes, horloge serveur.

Etat: {id,version,name,date,location,mode:'national'|'international',status:'preparation'|'running'|'finished',demo,rules_version,restore_id,bibs_distributed,people:[],entries:[],categories:[],officials:[],users:[],rounds:[],active_round_id:null,public:{main:{},secondary:{},backstage:{}},alerts:[],rewards:[],exam_programs:[],settings:{collective_tiebreak,regulations_checked:false},audit:[]}. Chaque objet id:string. Collections tableaux; dates ISO. API redacted par rôle.

Person: {id,first_name,last_name,birth_date,sex:'M'|'F',nationalities:['CI'],country,club,section:'amateur'|'pro',status_approved,delegation_approved,organizer_approved,licence_ok,payment_ok,minor_authorization,height_cm:string,weight_kg:string,measurements_confirmed,photo_portrait:null|id,photo_full:null|id,photo_approved:false,photo_consent:false,private_contact,pronunciation}. Entry: {id,person_id,category_id,bib:null|int,confirmed,derogation:null,origin_category_id}. Cat: {id,name,discipline,sex,section,division:'senior'|'junior'|'masters',age_min:null|int,age_max:null|int,rule_id,order,entry_ids:[],quota:6,elimination_quota:15,phase_override:null,merged_from:[],archived:false,active:true}. `active` (PO, 26/09/2026) : seules les catégories actives reçoivent des inscriptions, des dossards et des manches ; absent dans un ancien état = true ; une catégorie désactivée conserve ses inscriptions. Official profile: {id,first_name,last_name,post,organization,country,pedigree,photo_id,photo_consent,photo_approved}. User: {id,name,roles:[],approved,active} (codes/hashes never in state). Roles: chief,responsable,director,judge,trainee,secretariat,regie,speaker,commission. Director cannot vote even with other role.

Round: {id,category_id,discipline,section,phase:'elimination'|'semi'|'final'|'overall',status:'pending'|'open'|'awaiting_validation'|'validated'|'published'|'suspended',participant_ids:[entry_id],panel:[user_id],trainees:[user_id],withdrawal_order:[],quota,ballots:{user_id:{ranking:[entry_id] OR selected:[entry_id],received_at,original:{...},version,source:'digital'|'paper'}},trainee_deadline:null|unix_seconds,expired_trainees:[],transitioned:false,result:null|{common,official,qualified,version,validated_by},correction:null}. IDs in ballots are entry ids, not person ids or bibs. National eligible computed from CI nationality, never country alone. For international delegation+organizer flags needed. State also includes `me`, `server_time`, `catalogue_version`.

Commands (payload):

- person.save {person:Person}; entry.save {entry:Entry}; measurement.save {person_id,height_cm,weight_kg}; category.save {category:Cat} (accepte `active`); category.activate {category_id,active:boolean} (chef/responsable ; autorisé après dossards et compétition démarrée tant que la catégorie n'a pas commencé ; désactiver retire ses manches en attente sans bulletin, réactiver n'en recrée pas ; refusé sur une catégorie archivée) → Cat; category.fuse {category_ids,name}; programme.reorder {category_ids}; bibs.assign {}; entry.late {person,category_id,reason} (entry.save et entry.late : plusieurs catégories actives par athlète pour tout rôle de préparation, jamais deux fois la même, cumul amateur/pro interdit, catégorie désactivée refusée « Catégorie désactivée. ») ; entry.remove {entry_id} (préparation ; refusé si la catégorie a commencé ; la fiche reste) → {entry_id,person_id,category_id}; category.delete {category_id} (chef ; refusé si commencée ; inscriptions et manches en attente retirées) → {category_id,inscriptions_retirees}; person.delete {person_ids:[id]} (chef ; refusé si une catégorie de la personne a commencé ; retire inscriptions, dossards et photos) → {supprimes,person_ids,inscriptions_retirees}.
- official.save {official:Official}; user.invite {name,roles,code}; user.approve {user_id}; user.deactivate {user_id} (chef); user.update {user_id,name?,roles?,code?} (chef ; le rôle chef ne se modifie pas ; un nouveau code coupe les sessions du compte) → {user}; user.delete {user_id} (chef ; refusé si le compte a siégé ou voté, jamais sur soi) → {user_id}; official.delete {official_id} (chef ; photo effacée, écran public remis à idle) → {official_id}; jury.configure {panel,trainees,withdrawal_order}; round.configure {round_id,panel,trainees,quota}; programme.generate {} creates rounds; round.open {round_id}; round.next {}; round.validate {round_id,qualified_ids?}; round.correct {round_id,judge_id,ranking|selected,reason}; correction.sign {round_id}; round.incident {round_id,reason}; round.resolve {round_id,reason}; panel.reduce {round_id,remove_ids,reason}.
- overall.create {discipline,section,exam_user_ids?:[user_id]}; overall.confirm {round_id}; discipline.advance {discipline} after reward cycles explicit.
- scene.set {screen:'main'|'secondary'|'backstage',scene:{kind:'idle'|'category'|'qualifiers'|'reveal'|'podium'|'ranking'|'official'|'officials',category_id?,round_id?,official_id?,official_ids?,called_entry_id?,revealed_count?,positions?:{entry_id:zone}}}. Public GET /public/{screen}; filtered approved publicdata; never private balloting; `/screen/main`, `/screen/secondary`, `/screen/backstage`, `/screen/speaker` frontend routes.

- ballot.submit {round_id,ranking OR selected,restore_id}; paper.submit {round_id,judge_id,ranking OR selected,signature,reason}; chief-only paper with original recorded. Local drafts IndexedDB scoped event/restore/judge/round/version, never silent send.
- GET /eligibility/{person_id} proposals; GET /exams; GET /collective.
- GET /concordance (chef et responsable uniquement, 403 sinon ; PO 26/09/2026) → {chief_id, rounds:[{round_id,category_id,phase,status,reference_source:'validated'|'ballot',reference_version,judges:[{user_id,trainee,score:null|{numerator,denominator,display},pairs,comparable}]}], judges:[{user_id,trainee,mean,rounds,pairs}]} : même formule que l'examen (paires concordantes sur le bulletin original du juge, moyenne non pondérée), référence = bulletin du chef gelé à la validation sinon son bulletin courant ; manche sans bulletin du chef et éliminatoires absentes ; jamais dans l'état ni en public.
